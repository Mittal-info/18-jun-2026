variable rules : 

1) we can't use predefined keyword as a variable name 

    e.g.  int  int X 
          int float X 

          int  INT correct 
        
2) we can't add whitespace in variable name 

        e.g. int subject score   X 

3) variable name can contain only A to Z , a to z , 0 to 9 digits and _ (underscore) only.

        e.g. int subject_score; 

4) we can't start variable name with digits 

        e.g.  int  01num   X 
              
              int  num1;  correct

-----------------------------------
i) if statement :

    if (condition)

        // true statement;
    }

 ii) if..else statements:

 ----------------------------------
 iii) elif statement:

    when we want to check  multiple conditions at that time we have to use else ..if statement

        syntax:
          if(condition)
          {
            statement;
          }
          else if(condition)
          {
            statement;33
          }
          else if(condition)

 iv) nested if statement:

   when if condition call inside the another if condition.

   if(condition)
   {

    if(condition)
    {
        statement
    }
    else
    {
        statement
    }

   }
   else
   {
      statement
   }

   --------------------------------------------------------
     v) switch statement:when we want to perform multiple condition

         note:switch statement does not  support float data type
         
         syntax: 
         switch(expression)
         {
            case value:
            statement;
            break;

            case value:
            statement;
            break;

            case value:
            statement;
            break;

            default:
            statement;
         }

   ---------------------------------------------

   looping statement:

      when we want to display specific statement multiple times we can use loop statement.

      in c programing there are three types of loop

      1)For loop
      2)while...loop
      3)do...while loop
      ----------------------------------------------

         1)For loop: for loop is a sequence control loop.

         syntax:

           for(counter1;counter2;counter3)
           {
            statement;
           } 

           for(initlization;condition;updation)
           {
            statement;
           }   
        ----------------------------------------------


        2)while...loop:
    
          while loop is an entry controlled loop

           syntax:
           initialization;
           while(condition)
           {
            //block of code;
            updation;
           }
       ----------------------------------------------
     3) jumping statements:

         There are  three types of jumping statements
      1)break
                  
                   syntax:
                     break;                   

      2)continue: skip the current statement and loop will continue
 
                     syntax:
                        continue;
                    
      3)go to: goto is a jumping statement which means jump to specific part of program.

                       syntax:
                           goto <label>;
                            label:block of code
