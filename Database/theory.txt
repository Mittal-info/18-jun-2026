3)TRUNCATE :
  
         TRUNCATE command which mainly use to remove all rows from the table.

         in a simple language we can say that TRUNCATE command remove all data from the table.

         difference between drop and TRUNCATE:

         DROP: completly remove table from the database.

         after executation of drop command we can't find out table in memory.

         TRUNCATE: using of TRUNCATE we can just deleting all records from the table
                   not destroying table from the database.


         DROP: remove data,remove structure,remove table

         TRUNCATE:remove data,remove structure as it is and table as it is          

         
       syntax:
             TRUNCATE table <tablename>;

             e.g.

               id       name     subject
               1        Anjali   Python
               2        Mittal   Java

             by Default increment by 1 when executation TRUNCATE command it reset 
             counter from 1.

 6)Forign key::

              which is mainly use to connect with another table.

              when we want to provide relationship between two tables we have to 
              use foregin key.

              create table department
              (
                id int primary key auto_increment,
                d_name varchar(20)
              );

              1 IT           
              2 ADMIN

              create table employee
              (
                id int primary key auto_increment,
                name varchar(20),
                d_id int,
                foregin key (d_id) references department(id)
